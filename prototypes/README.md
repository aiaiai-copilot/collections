# Прототипы «Коллекций»

Все артефакты одноразовые, не используют backend и хранят состояние только в памяти вкладки.

## Изолированная лаборатория DAG-навигации

Самостоятельный UI-прототип варианта A: выбранные теги сверху, непрокручиваемое
облако направлений вниз. Приложение, формы, карточки результатов, создание
сущностей, тосты, шапка и нижняя навигация сюда не входят. Синтетические
сценарии, инспектор состояния и журнал событий находятся в технической оболочке
вокруг компонента.

Запуск из корня репозитория:

```sh
python3 prototypes/serve-dag-navigation-lab.PROTOTYPE.py
```

Открыть `http://127.0.0.1:8876/dag-navigation-lab.PROTOTYPE.html?scenario=roots`.
Сценарий можно передать через `?scenario=roots|parents|deep|temporary|overflow|scale|all`.
Минимальный исследуемый контракт записан в
`prototypes/dag-navigation-lab.CONTRACT.md`.

Сжатие скрывает только избыточные направления, сохраняя путь к каждому
потомку. Размер и масштаб ограничиваются полным покрытием. Если обязательные
направления не помещаются во всю область, лаборатория явно сообщает об этом.

## Основной интерфейс коллекции

UI-прототип для решения задачи «Найти основной интерфейс коллекции».

Запуск из корня репозитория:

```sh
python3 -m http.server 4174 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:4174/prototypes/collection-workspace.PROTOTYPE.html?variant=A`.

Варианты переключаются стрелками внизу экрана или клавишами `←` и `→`:

- `A` — постоянная боковая панель сохранённых фильтров;
- `B` — порядок показан как горизонтальная лента;
- `C` — заметное действие продолжения становится центром экрана.

Прототип проверяет расположение прямой расстановки, но намеренно не решает, как она меняет общий порядок относительно скрытых объектов.

## Глоссарий тегов

Mobile-first UI-прототип ручного глоссария без автоматических предложений. Три варианта сравнивают каталог, поиск как главный вход и инспектор одной записи; во всех доступны создание, редактирование, синонимы, архивирование, восстановление и объединение.

Открыть двойным кликом `prototypes/tag-glossary-manual.PROTOTYPE.html` — вариант A откроется по умолчанию. Через локальный сервер: `http://127.0.0.1:4174/prototypes/tag-glossary-manual.PROTOTYPE.html?variant=A`.

Варианты переключаются стрелками над основным меню или клавишами `←` и `→`:

- `A` — каталог активных и архивных записей;
- `B` — поиск и явное создание неизвестного названия;
- `C` — последовательная работа с одной записью.

Выбранная основа — `A`. В неё перенесены явное создание неизвестного названия из B и детальная форма записи из C; дальнейшие изменения относятся только к A.

### Отложенное исследование автоматических предложений

Logic-прототип автоматических предложений, кандидатов и отклонений сохранён как первичный источник будущей необязательной премиальной функции. Он не является интерфейсом текущего PoC.

Открыть двойным кликом `prototypes/tag-glossary.PROTOTYPE.html` или через тот же локальный сервер: `http://127.0.0.1:4174/prototypes/tag-glossary.PROTOTYPE.html`.
