# Интерфейс прежнего продуктового прототипа

Статус: сохранённые правила прежнего прототипа, перенесённые из CONTEXT.md
2026-10-15 без изменения текста. Это материал происхождения решений,
не автоматически принятый интерфейс текущего MVP.

Возврат: [предметная модель основы](../../CONTEXT.md).
Применимость к выпуску определяется [спецификацией MVP](../product/mvp-scope.md).

## Принципы интерфейса

- При прочих равных экран разгружается: постоянно показывается только информация, необходимая для текущего решения. Дополнительный контекст появляется перед действием, по запросу или как краткая неблокирующая обратная связь на том же экране.
- Цвет завершённости един во всём интерфейсе: всё незавершённое обозначается бледно-красным, всё завершённое — бледно-зелёным.
- Карта общего порядка является общей моделью коллекции и сортировки, но не обязана постоянно показываться отдельной панелью: на экране состояния достаточно статуса, ключевых показателей и действий, а полный порядок открывается по запросу в завершённом результате.
- Основная навигация вертикальна и последовательна: корневой экран показывает прокручиваемый список коллекций, экран коллекции — список её подборок, экран подборки — отфильтрованный список её элементов, экран элемента — сам элемент.
- Верхняя шапка экрана использует стрелку назад без видимой подписи. Экран списка подборок называется `Подборки из коллекции <Название коллекции>`, экран подборки — `Подборка <Название подборки> из коллекции <Название коллекции>`; имена сущностей в контекстной фразе выделяются плотным начертанием и фоном, а экран действия формулирует главное действие.
- Поиск элемента при добавлении в подборку одновременно служит точкой создания: если совпадений нет и введённого названия достаточно, `Enter` сразу создаёт элемент. Если модель потребует другие обязательные поля, `Enter` переводит к заполнению только этих полей; отдельный постоянный компонент создания под поиском не показывается.
- После создания коллекции или подборки интерфейс возвращается к родительскому списку и показывает новую строку в нём; созданная сущность не открывается автоматически.
- При появлении экрана создания клавиатурный фокус сразу устанавливается в главное первое поле: название коллекции, название подборки, поиск элемента для подборки либо название нового элемента для «Вся коллекция».
- Экран создания подборки явно называет родительскую коллекцию в основном заголовке: `Новая подборка из «Название коллекции»`.
- На экране элемента редактирование открывается напрямую по иконке карандаша в шапке, без промежуточного меню. Отдельная форма изменяет название и теги; изменение тегов сразу пересчитывает принадлежность всем подборкам. Удаление элемента требует подтверждения с явным предупреждением, что он полностью удалится из коллекции и всех подборок, сделанных из неё.
- В верхней части web-экрана показывается цепочка `Коллекции → Коллекция → Подборка → Элемент`. Её предки являются настоящими ссылками, а текущий адрес можно скопировать для передачи другому пользователю; production-ссылка должна быть стабильной и адресовать сущности по идентификаторам, а не хранить всё состояние в URL.
