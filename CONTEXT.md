# Предметная модель основы продукта

Родитель: [Идея продукта](docs/product/product-design.md).
Связь: детализация — определяет понятия коллекций, элементов, тегов, фильтров и подборок.

Основа продукта остаётся в родительском документе. Здесь уточняются её
понятия; сравнение не является условием существования коллекции.

## Область действия

Словарь общей модели шире первого выпуска. Ручные подборки, глобальный
поиск не входят в текущий MVP.
Для выпуска действуют [его ограничения](docs/product/mvp-scope.md);
контракт Навигатора рассматривает подборки, определяемые теговым фильтром.

## Language

**Пользователь**:
Приглашённый человек, которому единолично принадлежат его коллекции и связанные с ними данные. Один пользователь не видит и не изменяет данные другого.
_Avoid_: аккаунт, участник, владелец пространства

**Коллекция**:
Идентифицируемая постоянная и потенциально большая совокупность элементов. Коллекция задаёт область существования элементов и тегов; подборки представляют наборы элементов внутри неё. Требование попарной сравнимости относится к расширению сравнения, а не к основе продукта.
_Avoid_: сессия, очередь пар, срез

**Тег**:
Короткая метка элемента, по которой элементы коллекции группируются и фильтруются. Тег не является критерием выбора и не выражает отношение между объектами.
_Avoid_: критерий выбора, рейтинг

**Разметка тегами**:
Назначение тегов объекту, выполненное пользователем напрямую либо после подтверждения автоматического предложения. Неподтверждённое предложение разметкой не является; при наличии глоссария разметка использует только его записи.
_Avoid_: автоматическая разметка, сортировка, классификация коллекций

**Фильтр по тегам**:
Изменяемый набор тегов, ограничивающий видимый состав коллекции объектами, содержащими каждый выбранный тег. Фильтр не меняет состав коллекции и не является критерием выбора.
_Avoid_: критерий выбора, отдельная коллекция

**Текущий фильтр**:
Изменяемый фильтр открытой подборки. Он может быть получен из подборки, но после изменения набора тегов или явного имени считается несохранённым и не меняет исходную подборку. Пустой фильтр охватывает всю коллекцию.
_Avoid_: подборка, срез

**Контекстный поиск**:
Временное уточнение по тегам внутри открытой коллекции или фактического состава открытой подборки. В автоматической подборке поисковые теги дополняют её фильтр, а в ручной не выводят поиск за пределы явно включённых элементов; сохранённый фильтр при этом не меняется.
_Avoid_: изменение фильтра подборки, глобальный поиск

**Глобальный поиск**:
Поиск по элементам всех коллекций с сохранением контекста родительской коллекции в каждом результате. Принадлежность коллекции определяется структурной связью, а не служебным пользовательским тегом.
_Avoid_: контекстный поиск, уникальный тег коллекции

**Подборка**:
Именованное сохраняемое представление элементов коллекции, состав которого определяется автоматически фильтром либо явно как ручной набор. Внутренняя системная проекция «Вся коллекция» охватывает весь состав, но не является пользовательской подборкой.
_Avoid_: подколлекция, папка, сохранённый фильтр, сохранённый срез

**Автоматическая подборка**:
Подборка, фактический состав которой вычисляется по актуальному содержимому родительской коллекции и сохранённому теговому фильтру. Отдельное членство элементов в ней не сохраняется.
_Avoid_: filter-based подборка, умная подборка

**Ручная подборка**:
Подборка с явно зафиксированным составом, который меняется только ручным добавлением или исключением элементов. Она может быть создана сразу либо получена из автоматической подборки после подтверждённого отклонения от её фильтра.
_Avoid_: папка, автоматическая подборка с исключениями

**Принадлежность элемента подборке**:
В автоматической подборке элемент принадлежит ей при соответствии актуальному фильтру, а в ручной — при явном включении в её зафиксированный состав. Независимо от подборок элемент всегда принадлежит родительской коллекции.
_Avoid_: единое правило членства для автоматических и ручных подборок

**Без подборки**:
Вычисляемое системное представление элементов, фактически не принадлежащих ни одной пользовательской подборке: ни автоматической по фильтру, ни ручной по зафиксированному составу. Внутренняя «Вся коллекция» при этом не учитывается.
_Avoid_: спецподборка, папка неразобранного

**Порядок элементов подборки**:
Последовательность элементов подборки, которая может быть произвольной, определяться способом сортировки или задаваться пользователем. Способ определения порядка не меняет способ определения состава подборки.
_Avoid_: состав подборки, порядок самих подборок, общий порядок сравнения

**Способ упорядочивания элементов подборки**:
Полное задание упорядочивания: правило сортировки со всеми определяющими параметрами, заданный пользователем порядок или отсутствие заданного упорядочивания. Вместе с точным теговым фильтром определяет автоматическую подборку в пределах коллекции, независимо от случайного совпадения текущих последовательностей элементов.
_Avoid_: только название сортировки, текущий результат сортировки

**Активность подборки**:
Относительная мера использования подборки, по которой подборки упорядочиваются по умолчанию, если их порядок не закреплён.
_Avoid_: рейтинг среза, важность

**Закреплённый порядок подборок**:
Порядок подборок, который пользователь исключил из автоматического изменения по активности.
_Avoid_: закреплённая подборка

**Срез коллекции**:
Текущая часть коллекции, определённая фильтром по тегам; при пустом фильтре срез совпадает со всей коллекцией. Срез не является отдельной коллекцией и меняется вместе с фильтром и живой коллекцией.
_Avoid_: подколлекция, результат сортировки

## Термины теговой навигации

**Узлы одного уровня**:
Узлы в одной области данных Навигатора, у которых в точности совпадает полный нормализованный теговый фильтр; различие способов упорядочивания не меняет уровень. В этом продуктовом смысле уровень не определяется числом тегов, глубиной пути, общим родителем или положением на экране.
_Avoid_: одинаковая глубина, одинаковое число тегов, любые соседние узлы

**Горизонтальный переход**:
Переход из текущего узла в другой узел того же уровня, сохраняющий полный теговый фильтр. В частности, переход из одной автоматической подборки в другую с тем же фильтром и иным способом упорядочивания является горизонтальным.
_Avoid_: уточнение, расширение, произвольная замена тегов

**Глубина узла**:
Максимальное число узлов в цепочке последовательных строгих уточнений от любого корня рассматриваемого тегового DAG до данного узла включительно. Глубина корня равна 1; горизонтальные переходы и фактический маршрут пользователя не учитываются.
_Avoid_: уровень узла, число тегов, число рёбер, длина пользовательского маршрута

**Глубина графа**:
Максимальная глубина его узлов; глубина пустого графа равна 0. Рассматриваемый граф должен быть указан явно — например, граф сохранённых подборок или граф с промежуточными узлами; искусственный корень «Всё» только ради подсчёта не добавляется.
_Avoid_: количество уровней теговой навигации, число тегов
