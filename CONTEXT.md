# Коллекции и общий порядок сравнения

Контекст описывает работу с большими постоянными коллекциями, их подборками по тегам и единым транзитивным порядком, который постепенно дополняется решениями пользователя.

## Принципы интерфейса

- При прочих равных экран разгружается: постоянно показывается только информация, необходимая для текущего решения. Дополнительный контекст появляется перед действием, по запросу или как краткая неблокирующая обратная связь на том же экране.
- Цвет завершённости един во всём интерфейсе: всё незавершённое обозначается бледно-красным, всё завершённое — бледно-зелёным.
- Карта общего порядка является общей моделью коллекции и сортировки, но не обязана постоянно показываться отдельной панелью: на экране состояния достаточно статуса, ключевых показателей и действий, а полный порядок открывается по запросу в завершённом результате.
- Основная навигация вертикальна и последовательна: корневой экран показывает прокручиваемый список коллекций, экран коллекции — список её подборок, экран подборки — отфильтрованный список её элементов, экран элемента — сам элемент.
- Верхняя шапка экрана использует стрелку назад без видимой подписи. Экран списка подборок называется `Подборки из коллекции <Название коллекции>`, экран подборки — `Подборка <Название подборки> из коллекции <Название коллекции>`; имена сущностей в контекстной фразе выделяются плотным начертанием и фоном, а экран действия формулирует главное действие.
- Поиск элемента при добавлении в подборку одновременно служит точкой создания: если совпадений нет и введённого названия достаточно, `Enter` сразу создаёт элемент. Если модель потребует другие обязательные поля, `Enter` переводит к заполнению только этих полей; отдельный постоянный компонент создания под поиском не показывается.
- После создания коллекции или подборки интерфейс возвращается к родительскому списку и показывает новую строку в нём; созданная сущность не открывается автоматически.
- При появлении экрана создания клавиатурный фокус сразу устанавливается в главное первое поле: название коллекции, название подборки, поиск элемента для подборки либо название нового элемента для «Вся коллекция».
- Экран создания подборки явно называет родительскую коллекцию в основном заголовке: `Новая подборка из «Название коллекции»`.
- На экране элемента редактирование открывается напрямую по иконке карандаша в шапке, без промежуточного меню. Отдельная форма изменяет название и теги; изменение тегов сразу пересчитывает принадлежность всем подборкам. Удаление элемента требует подтверждения с явным предупреждением, что он полностью удалится из коллекции и всех подборок, сделанных из неё.
- В верхней части web-экрана показывается цепочка `Коллекции → Коллекция → Подборка → Элемент`. Её предки являются настоящими ссылками, а текущий адрес можно скопировать для передачи другому пользователю; production-ссылка должна быть стабильной и адресовать сущности по идентификаторам, а не хранить всё состояние в URL.

## Language

**Пользователь**:
Приглашённый человек, которому единолично принадлежат его коллекции и связанные с ними данные. Один пользователь не видит и не изменяет данные другого.
_Avoid_: аккаунт, участник, владелец пространства

**Объект сравнения**:
Визуально обозримая сущность, которую пользователь может оценить как единое целое; в текущем контексте это короткий текст или изображение.
_Avoid_: вариант, кандидат, карточка

**Версия объекта сравнения**:
Неизменяемая фиксация содержимого и представления объекта, непосредственно показанного пользователю при сравнении. Изменение объекта создаёт новую версию, не меняя прежние сравнения и результаты.
_Avoid_: текущий объект, исправленный результат

**Коллекция**:
Идентифицируемая постоянная и потенциально большая совокупность попарно сравнимых объектов. Практическая, не строгая граница коллекции — возможность адекватно сравнить любую пару по одному критерию: принципиально разные форматы обычно разделяются по коллекциям, а тематические классы сравнимых объектов различаются тегами.
_Avoid_: сессия, очередь пар, срез

**Тег**:
Короткая метка объекта сравнения, по которой элементы коллекции группируются и фильтруются. Тег не является критерием выбора и не выражает отношение между объектами.
_Avoid_: критерий выбора, рейтинг

**Разметка тегами**:
Назначение тегов объекту, выполненное пользователем напрямую либо после подтверждения автоматического предложения. Неподтверждённое предложение разметкой не является; при наличии глоссария разметка использует только его записи.
_Avoid_: автоматическая разметка, сортировка, классификация коллекций

**Предложение тега**:
Не изменяющая данные автоматическая рекомендация назначить существующий тег либо создать новую запись глоссария. Предложение становится разметкой или записью глоссария только после явного подтверждения пользователя.
_Avoid_: автоматическая разметка, назначенный тег

**Отклонение предложения тега**:
Сохранённое решение пользователя не предлагать конкретный тег конкретному объекту. Оно действует бессрочно, не распространяется на другие пары «объект + тег» и снимается только явным действием пользователя.
_Avoid_: временно скрытое предложение, удалённый тег

**Глоссарий тегов**:
Необязательный управляемый словарь тегов коллекции, который поддерживает единообразную разметку и исключает появление случайных синонимов и вариантов написания. Если глоссарий используется, теги объектов и фильтров ссылаются только на его записи; неизвестное название сначала явно создаётся в глоссарии и лишь затем назначается объекту или включается в фильтр.
_Avoid_: фильтр, критерий выбора

**Архивный тег**:
Обратимо выведенная из употребления запись глоссария. Она недоступна для новых назначений, новых фильтров и автоматических предложений, но сохраняет прежние ссылки объектов и фильтров, остаётся в них видимой с архивным статусом и может быть восстановлена.
_Avoid_: удалённый тег, неиспользуемый тег

**Объединённый тег**:
Историческая запись глоссария, все ссылки которой перенесены на другой канонический тег при объединении дублей. Она показывает, с каким тегом была объединена, но не является архивным тегом и не может быть восстановлена напрямую.
_Avoid_: архивный тег, удалённый тег, синоним тега

**Синоним тега**:
Неназначаемое альтернативное обозначение одной записи глоссария, используемое для поиска и автоматического распознавания. Активные основные названия и синонимы образуют единое пространство имён: одно нормализованное обозначение не может принадлежать разным тегам.
_Avoid_: отдельный тег, тег объекта

**Переименование тега**:
Изменение отображаемого названия существующего тега без изменения его смысла и идентичности. Объекты и фильтры продолжают ссылаться на тот же тег и показывают его новое название.
_Avoid_: замена тега, новый тег

**Замена тега**:
Смена разметки выбранных объектов или фильтров с одного тега на другой самостоятельный тег из-за различия смысла. Исходный тег сохраняет собственную идентичность и может быть архивирован отдельно.
_Avoid_: переименование тега, удаление и повторное создание тега

**Объединение тегов**:
Необратимое сведение двух признанных дублей к одной канонической записи. Все ссылки объектов, текущих и сохранённых фильтров переносятся на целевой тег, прежнее название и синонимы исходного становятся синонимами целевого, а исходная запись становится объединённым тегом. Живые срезы пересчитываются, но уже начатые сравнения сохраняют свои зафиксированные версии срезов.
_Avoid_: переименование тега, замена тега, архивирование тега

**Фильтр по тегам**:
Изменяемый набор тегов, ограничивающий видимый состав коллекции объектами, содержащими каждый выбранный тег. Фильтр не меняет состав коллекции и не является критерием выбора.
_Avoid_: критерий выбора, отдельная коллекция

**Текущий фильтр**:
Изменяемый фильтр открытой подборки. Он может быть получен из подборки, но после изменения набора тегов или явного имени считается несохранённым и не меняет исходную подборку. Пустой фильтр охватывает всю коллекцию.
_Avoid_: подборка, срез

**Контекстный поиск**:
Временное уточнение по тегам внутри открытой коллекции или фактического состава открытой подборки. В автоматической подборке поисковые теги дополняют её фильтр, а в ручной не выводят поиск за пределы явно включённых элементов; сохранённый фильтр при этом не меняется.
_Avoid_: изменение фильтра подборки, глобальный поиск

**Глобальный поиск**:
Поиск по элементам всех коллекций с сохранением контекста родительской коллекции в каждом результате. Принадлежность коллекции определяется структурной связью, а не служебным пользовательским тегом.
_Avoid_: контекстный поиск, уникальный тег коллекции

**Подборка**:
Именованное сохраняемое представление элементов коллекции, состав которого определяется автоматически фильтром либо явно как ручной набор. Внутренняя системная проекция «Вся коллекция» охватывает весь состав, но не является пользовательской подборкой.
_Avoid_: подколлекция, папка, сохранённый фильтр, сохранённый срез

**Автоматическая подборка**:
Подборка, фактический состав которой всегда совпадает с актуальным результатом её фильтра по тегам. Отдельное членство элементов в ней не сохраняется.
_Avoid_: filter-based подборка, умная подборка

**Ручная подборка**:
Подборка с явно зафиксированным составом, который меняется только ручным добавлением или исключением элементов. Она может быть создана сразу либо получена из автоматической подборки после подтверждённого отклонения от её фильтра.
В интерфейсе обозначается нейтрально акцентированной строкой с пиктограммой и текстовой меткой «Ручная»; красный и зелёный для различения типа не используются.
_Avoid_: папка, автоматическая подборка с исключениями

**Принадлежность элемента подборке**:
В автоматической подборке элемент принадлежит ей при соответствии актуальному фильтру, а в ручной — при явном включении в её зафиксированный состав. Независимо от подборок элемент всегда принадлежит родительской коллекции.
_Avoid_: единое правило членства для автоматических и ручных подборок

**Без подборки**:
Вычисляемое системное представление элементов, фактически не принадлежащих ни одной пользовательской подборке: ни автоматической по фильтру, ни ручной по зафиксированному составу. Внутренняя «Вся коллекция» при этом не учитывается.
_Avoid_: спецподборка, папка неразобранного

**Активность подборки**:
Относительная мера использования подборки, по которой подборки упорядочиваются по умолчанию, если их порядок не закреплён.
_Avoid_: рейтинг среза, важность

**Закреплённый порядок подборок**:
Порядок подборок, который пользователь исключил из автоматического изменения по активности.
_Avoid_: закреплённая подборка

**Срез коллекции**:
Текущая часть коллекции, определённая фильтром по тегам; при пустом фильтре срез совпадает со всей коллекцией. Срез не является отдельной коллекцией и меняется вместе с фильтром и живой коллекцией.
_Avoid_: подколлекция, результат сортировки

**Обозримый срез**:
Срез, объекты которого пользователь может одновременно увидеть и осмысленно расставить в текущем представлении и на текущем устройстве. Обозримость контекстна и не задаётся единым числом элементов.
_Avoid_: маленькая коллекция, фиксированный лимит

**Версия среза коллекции**:
Неизменяемая фиксация фильтра и входящих в срез версий объектов на момент запуска сравнения. Сравнение относится к одной версии среза и не переходит на изменившийся срез без явного решения пользователя.
_Avoid_: подколлекция, текущий фильтр

**Критерий выбора**:
Необязательное устойчивое основание выбора между объектами с обязательным коротким названием и необязательным пояснением. Отношения по разным критериям не смешиваются, а без критерия пользователь оценивает объекты «в целом».
_Avoid_: фильтр, рейтинг

**Общий порядок сравнения**:
Накопленное транзитивное отношение между версиями объектов одной коллекции для одного критерия, включая оценку «в целом» без критерия. Оно может оставаться частичным; сравнения разных срезов используют и дополняют его, поэтому общие объекты сохраняют одинаковый относительный порядок. Если общий порядок стал полным для некоторого среза, любой входящий в него срез также считается полностью упорядоченным без дополнительных сравнений.
_Avoid_: результат сортировки, порядок отдельного среза

**Неупорядоченный объект среза**:
Версия объекта, отношение которой хотя бы с одной другой версией объекта текущего среза не выводится из общего порядка сравнения. Объект может уже иметь отношения с частью среза и не обязан быть новым.
_Avoid_: новый объект, несравнённый объект

**Пара сравнения**:
Два совместимых объекта сравнения, одновременно предоставленных пользователю для одного решения.
_Avoid_: раунд, матч

**Непрерывный цикл сравнения**:
Основной интерактивный режим сортировки, в котором каждый тап по объекту или равноценности сразу фиксирует исход и показывает следующую необходимую пару. Пересчёт порядка выполняется в фоне и не прерывает цикл отдельным экраном; полезная попутная обратная связь показывается неблокирующим сообщением поверх того же экрана сортировки. Пользователь выходит явно либо после завершения всего сравнения.
_Avoid_: подтверждение каждого исхода, экран пересчёта после пары, пошаговый мастер

**Источник пар**:
Поставщик пар сравнения, который определяет следующее необходимое сравнение с учётом уже известных отношений. Получатель пары не обязан знать будущие объекты или способ их подбора.
_Avoid_: коллекция

**Цель сравнения**:
Неизменное в пределах одного сравнения условие достаточности результата, которое определяет необходимые отношения между объектами и момент завершения.
_Avoid_: сценарий использования, критерий выбора

**Сравнение**:
Долговременный сохраняемый процесс получения одного результата для одной версии среза, одного необязательного критерия и одной цели сравнения. Сравнения отдельно приостанавливаются и возобновляются, но используют и дополняют общий порядок своей коллекции и критерия.
_Avoid_: задача, поручение, сессия, коллекция, попытка

**Сортировка среза**:
Вид сравнения, цель которого — дополнить общий порядок до полного транзитивного порядка объектов зафиксированного среза. Уже известные из других срезов отношения повторного сравнения не требуют.
_Avoid_: отдельный порядок среза, отбор элементов

**Незавершённая сортировка**:
Сортировка среза, ограничение общего порядка для которой ещё не стало полным и которая сохраняется для продолжения. Для больших срезов это нормальное долговременное состояние, а не ошибка или частичный результат.
_Avoid_: проваленная сортировка, черновик результата

**Пересмотр порядка**:
Явно начатое изменение уже установленных отношений общего порядка. Незавершённый пересмотр можно продолжить попарными решениями либо завершить на экране «Приоритеты», приняв накопленный к этому моменту порядок; закрытие экрана только приостанавливает пересмотр.
_Avoid_: неявная перезапись решения, обязательная полная пересортировка

**Исход пары**:
Зафиксированное пользователем отношение между объектами пары: левый лучше, правый лучше либо объекты равноценны. Равноценность означает общее место, а не отсутствие решения.
_Avoid_: голос

**Результат сравнения**:
Неизменяемая датированная фиксация версии среза и отношений между её объектами, достаточных для цели одного завершённого сравнения.
_Avoid_: действие над коллекцией, текущий порядок

**Результат сортировки**:
Неизменяемый датированный снимок версии среза и полного порядка её объектов на момент завершения сортировки. Он фиксирует ограничение общего порядка на этот срез, а не создаёт отдельный порядок.
_Avoid_: рейтинг, заранее заданный порядок

**Прогресс сравнения**:
Монотонная доля уже выполненной алгоритмической работы по текущему сравнению, которую источник выражает в процентах. Она не равна отношению сделанных сравнений к заранее обещанному общему числу.
_Avoid_: число выборов, число сравнений

**Оценка числа сравнений**:
Предварительная оценка количества исходов пар, необходимых для завершения сравнения при известном размере версии среза. Она может включать ожидаемое и максимальное значения, но не учитывает повторные показы отложенных пар.
_Avoid_: точное число сравнений, прогресс сравнения
