# Коллекции

## Принятое определение продукта

Корень продуктового решения — [Идея продукта](docs/product/product-design.md#идея-продукта).
В корне описана основа: коллекции, теги, фильтры, подборки, поиск и навигация.
Расширения раскрываются дочерними документами в
[иерархии](docs/product/README.md#иерархия-документов).

## Статус проекта и документы

Сейчас завершается проектирование ограниченного MVP перед передачей
исполнителю для реализации и доведения до production. Проект ещё не готов
к передаче; продуктовое определение не является заявлением о готовности кода.

Для проектирования, реализации и последующих переработок начинать с
[указателя проектной документации](docs/product/README.md). Содержание разделено:

- [Идея продукта](docs/product/product-design.md) — корень иерархии;
- [Предметная модель основы](CONTEXT.md) — определения коллекций, тегов, фильтров и подборок;
- [Навигация и получение результатов](docs/product/navigation-and-results.md) — контракты предметной навигации и общих механизмов;
- [Спецификация MVP](docs/product/mvp-scope.md) — состав и требования первого выпуска;
- [Технический проект MVP](docs/product/mvp-technical-design.md) — выбранные способы реализации;
- [Текущее состояние проектирования](docs/product/README.md#что-уже-определено-и-что-остаётся) — готовность и открытые вопросы.

Рабочие и справочные материалы:

- [Полный реестр документов](docs/product/document-register.md) — состав корпуса и роли материалов;
- [CONTEXT-MAP.md](CONTEXT-MAP.md) — разграничение действующей модели и альтернативных исследований;
- [Проектирование MVP](.scratch/mvp-design/map.md) — текущая карта решений;
- [BACKLOG.md](BACKLOG.md) — отложенные продуктовые возможности;
- [HANDOFF.md](HANDOFF.md) — текущее состояние между сессиями;
- [Первоначальная карта](.scratch/collections/map.md) — решения раннего этапа;
- [Материалы предыдущего проекта](references/legacy.md) — точечные референсы.

Предыдущий репозиторий не является источником требований: его материалы используются только через явно перечисленные референсы.
