# Коллекции

Локальный интерактивный PoC для работы с длинными постоянными коллекциями, теговыми срезами и общим транзитивным порядком, который постепенно дополняется попарными сравнениями.

Проект находится на стадии продуктового моделирования и прототипирования. Канонические источники:

- `CONTEXT.md` — словарь предметной области;
- `BACKLOG.md` — короткий список отложенных продуктовых возможностей;
- `.scratch/collections/map.md` — карта `wayfinder`;
- `HANDOFF.md` — текущее состояние между сессиями;
- `references/legacy.md` — точечные ссылки на исследования предыдущего проекта.

Предыдущий репозиторий не является источником требований: его материалы используются только через явно перечисленные референсы.
