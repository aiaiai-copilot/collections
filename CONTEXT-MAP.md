# Контексты продукта «Коллекции и подборки»

Общий ориентир для всех участников разработки —
[принятое определение продукта](docs/product/product-design.md).

- [Предметная модель основы продукта](CONTEXT.md) — словарь коллекций, тегов, фильтров и подборок. Определения [глоссария](docs/product/tag-glossary.md), [сравнения](docs/product/comparison.md) и [продолжения сравнения](docs/product/comparison/continuation.md) находятся в соответствующих ветвях расширений.
- [Иерархия подборок](docs/concepts/selection-hierarchy/CONTEXT.md) — отдельное исследование продукта без выделенных коллекций, где подборки образуют семантический DAG по тег-фильтрам и отдельное навигационное дерево.

Контексты не смешиваются. До отдельного решения концепт «Иерархия подборок» является альтернативой, а не изменением действующей спецификации.

Это служебный указатель контекстов. Действующее дерево начинается с
[Идеи продукта «Коллекции и подборки»](docs/product/product-design.md); весь корпус материалов
перечислен в [реестре документов](docs/product/document-register.md).

Разрабатываемый из прототипа [DAG-навигатор](docs/concepts/selection-hierarchy/dag-navigator-upper-interface.DRAFT.md#область-данных-навигатора)
не предписывает выбор между этими продуктовыми концептами: приложение
задаёт ему область данных, которой может служить коллекция или личное
пространство. Это не перенос всех правил одного продуктового контекста в другой.
