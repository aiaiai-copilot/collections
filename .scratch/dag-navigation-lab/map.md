# Изолированная лаборатория DAG-навигации

Label: wayfinder:map

## Destination

Проверить mobile-first навигационный компонент по семантическому DAG отдельно от интерфейса приложения: пользователь должен понимать текущий узел, направления вверх и вниз, фактический возврат и выход в «Всё» при нескольких родителях, корнях, большой глубине и ограниченном прямоугольнике.

- Перед e2e/интеграционными проверками определить фактический API target. Лаборатория должна быть полностью статической и не иметь backend/API.

## Decisions so far

- Экран результатов, карточки подборок, создание сущностей, тосты, шапка и нижняя навигация приложения не входят в компонент.
- «Показать результаты» допустимо только как исходящее событие компонента; лаборатория не должна отображать экран результатов.
- Динамическое изменение графа, если понадобится для проверки, выполняется техническим контролом вне границ компонента.

## Not yet specified

- Точный публичный контракт состояния и событий компонента.
- Постоянное представление имени текущего сохранённого узла рядом с его набором тегов.
- Пользовательская оценка предела сжатия и автоматического включения прокрутки при крайнем переполнении.
- Метрика и визуальная шкала веса направлений.
- Оценка ручного ввода и переключения режимов на физическом touch-устройстве, экранная клавиатура и плотность облака при вводе; необходимость обоих режимов подтверждена, диалог оценён в сценарии `manual` (см. ручную проверку выше).
