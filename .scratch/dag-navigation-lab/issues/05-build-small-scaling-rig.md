# Подготовить малый эталон и индексный кандидат

Type: task
Status: resolved
Blocked by: 03, 04

## Question

Подготовить воспроизводимую проверку правильности двух вычислительных
кандидатов перед измерением границ масштабирования: независимого полного
перебора и обратного индекса. Это технический шаг исследования, не приёмка
производительности или изменение публичного контракта.

## Scope

Пользователь 2026-09-23 поручил продолжить после
[плана эксперимента](../../../docs/research/dag-navigator-scaling-experiment.PLAN.md).
Проверяемая граница из плана — четыре возможности источника, контрольная
страница внешнего хоста и полный вычисленный навигационный ответ. Методы
стенда не утверждают будущий API. Код временный, отдельно от принятого UI;
только маленькие синтетические данные, память и стандартный Node test runner.
Без сети, БД, установки зависимостей и нагрузочного прогона.

## Working method

Wayfinder, codebase-design, TDD. От prototype применяется явная маркировка
временного кода; интерактивное HTML-демо здесь не требуется. Его рекомендация
пропустить тесты не подходит задаче: проверка правильности — предмет опыта.
Проверки идут через согласованную в плане границу, без тестирования внутренних
структур индекса. Базовые ожидания ручные, затем дифференциальная проверка.

## Answer

2026-09-23 создан [малый вычислительный стенд](../../../prototypes/dag-scaling.PROTOTYPE/README.md)
в текущей исследовательской ветке. Реализованы независимый перебор
и обратные индексы элементов/фильтров, четыре возможности источника,
контрольная страница и общий сборщик ответа для `nodes` / `free`.
Общая логика навигации дополнительно проверяется ручными ожиданиями;
совпадение адаптеров не выдаётся за независимую проверку этой общей логики.

После циклов red → green прошли 34 теста, включая 7000 полных сравнений
(50 seed × 70 наборов × 2 режима), сверку сведений источника, покрытие
потомков, нулевые счётчики, дополнительные родители после уточнения,
отдельный пустой пользовательский узел и отсутствие top-N на 80 корнях.
Проверены недоступная ревизия, недоступный ID, смешанные ответы и неполный
пакет счётчиков. Ревизия лишь неизменного снимка, не реализация свежести
или пересборки при конкурентной записи.

Команда: `env -u NODE_OPTIONS -u NODE_PATH node --test prototypes/dag-scaling.PROTOTYPE/rig.test.mjs`.
Перед запуском проверены файлы и импорты: только локальные модули и
стандартный раннер, без backend/API target, `.env`, сети и зависимостей.
Повторный итоговый прогон: 34 passed, 0 failed; `git diff --check` без ошибок.
UI-прототип, продуктовый код и контракт не менялись. БД, серверы и большие
наборы не запускались; длительности тестов не являются benchmark.

Технический шаг завершён. Для измерений нужен отдельный ограниченный runner
с записью сырых результатов, контролем ресурсов и генератором масштабных
данных. Корректностный генератор остаётся малым; эксплуатационные гарантии
и выбор backend по этому опыту не принимаются.
