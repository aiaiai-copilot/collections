# Интерактивный PoC «Коллекций»

Label: wayfinder:map

## Destination

Работающий локальный интерактивный PoC, в котором пользователь поддерживает длинную именованную коллекцию, работает с явно сохранёнными теговыми фильтрами, видит упорядоченную и неупорядоченную части текущего среза и постепенно дополняет общий порядок по выбранному критерию прямой расстановкой обозримой части или сохраняемыми попарными сравнениями.

## Notes

- Карта включает продуктовые решения, работающий локальный прототип и первую интерактивную проверку, но не production-реализацию.
- Канонический словарь находится в `../../CONTEXT.md`; решения с участием пользователя обсуждаются по одному вопросу за сообщение.
- Для карты использовать `wayfinder`, для терминов — `domain-modeling`, для UI-вопросов — `prototype`, для архитектурных швов — `codebase-design`.
- Центральный сценарий — длинные постоянные коллекции, которые невозможно обозреть за один заход.
- Фильтр по тегам создаёт живой срез; несколько выбранных тегов соединяются пересечением.
- Базовую навигацию образуют явно сохранённые фильтры. Они существуют до удаления, могут иметь отдельное имя, по умолчанию упорядочиваются по активности; пользователь может закрепить порядок, а яркость может опционально отражать активность.
- Для одной коллекции и одного критерия, включая оценку «в целом», накапливается один общий транзитивный частичный порядок. Каждый срез показывает его ограничение и явно обозначает объекты, для которых отношений недостаточно до полного порядка.
- Сортировка фиксирует версию среза, использует уже известные отношения и дополняет общий порядок. Результат является неизменяемым снимком ограничения порядка на эту версию среза.
- Незавершённая сортировка большого среза является нормальным долговременным состоянием и должна легко возобновляться короткими подходами.
- Обозримый срез по умолчанию допускает прямую расстановку; влияние такой расстановки на общий порядок и скрытые объекты ещё требует решения.
- Первый PoC работает локально и адаптируется к компьютеру и телефону. Фактическая синхронизация между устройствами не требуется.
- Двухпанельный игровой цикл не перепроектируется без новой причины; проверенный референс указан в `../../references/legacy.md`.

## Decisions so far

- [Определить продуктовый центр «Коллекций»](issues/00-product-center.md): коллекция является основным постоянным объектом, сохранённый фильтр открывает живой срез, а задачи срезов дополняют общий порядок коллекции по критерию и создают снимки его ограничений.

## Not yet specified

- Возможные дополнительные решения о форматах коллекций и представлении общей упорядоченности прояснятся после проверки основного интерфейса.

## Out of scope

- Импорт, аккаунты, обмен коллекциями, серверное хранение и production-развёртывание.
- Отбор лучших или худших `N` и изменение состава коллекции на основании результата.
- Детальная система версий как самостоятельный пользовательский раздел.
- Копирование прежней карты, навигации сортировок или компоновки «Мастерская».
