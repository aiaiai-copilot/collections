# Найти основной интерфейс коллекции

Type: prototype
Status: claimed

## Question

Какой минимальный адаптивный интерфейс позволяет перемещаться по сохранённым фильтрам, работать с текущим живым срезом, видеть его неупорядоченную часть, прямо расставлять обозримый срез и запускать или продолжать попарное упорядочивание большого?

## Confirmed constraints

- Сохранённый фильтр остаётся до явного удаления, может иметь отдельное имя и без имени представлен набором тегов.
- Фильтры по умолчанию упорядочиваются по убыванию активности; пользователь может закрепить порядок. Яркость может опционально отражать активность.
- Незавершённые задачи являются контекстными действиями продолжения, а не постоянными пунктами основной навигации.
- Все срезы одной коллекции и критерия используют общий порядок; неупорядоченные объекты текущего среза видимы.
- Старый прототип коллекции является только историческим референсом.
