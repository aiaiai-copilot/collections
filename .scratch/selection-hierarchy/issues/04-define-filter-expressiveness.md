# Определить выразительность фильтров

Type: grilling
Status: resolved

## Question

Какие логические операции разрешены в тег-фильтре подборки: только пересечение обязательных тегов или также `OR`, `NOT` и более сложные выражения?

Решение должно сохранить однозначное отношение «шире → уже». Для простого пересечения оно проверяется включением наборов тегов; для сложных выражений потребуется более общее правило логического следования одного фильтра из другого.

## Answer

Тег-фильтр подборки является только пересечением обязательных тегов. `OR`, `NOT` и более сложные выражения не поддерживаются.

Элемент соответствует фильтру, если содержит все его теги; дополнительные теги не мешают соответствию. Поэтому дочерний фильтр уточняет родительский тогда и только тогда, когда множество тегов родителя является подмножеством множества тегов ребёнка. Пустой фильтр соответствует всему личному пространству элементов.

Позднее уточнено в решении «Определить жизненный цикл пользовательской иерархии подборок»: нормализованный тег-фильтр уникален в пределах личного пространства. Поэтому для двух разных подборок отношение уточнения соответствует строгому включению наборов тегов; попытка создать уже существующий фильтр обращается к существующей подборке.
